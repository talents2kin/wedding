# 08 — Invitation template catalog + digital delivery

**What to build:** A Wedding Admin or Editor can browse a catalog of platform-provided invitation Templates, select one, and preview how it will look for a specific Guest and Ceremony. Paid users can customise the Template's colours, fonts, and text before sending. The Admin or Editor can then send a digital Invitation to one or more Guests via their choice of email, SMS, or WhatsApp. Notification delivery status (sent / delivered / failed) is visible per Guest. Failed Notifications can be resent. Free-tier users can choose from the catalog but cannot customise Templates.

**Blocked by:** 04 — Ceremony management, 05 — Guest list — manual entry + groups.

**Status:** ready-for-agent

- [ ] A Wedding Admin or Editor can browse the platform Template catalog
- [ ] A Wedding Admin or Editor can preview a Template personalised with a Guest's name and Ceremony details
- [ ] A paid user can customise a Template's colours, fonts, and body text
- [ ] A free-tier user can select a Template but customisation controls are locked with an upgrade prompt
- [ ] A Wedding Admin or Editor can send a digital Invitation to one or more Guests, choosing email, SMS, or WhatsApp per send
- [ ] Each Notification has a delivery status: sent, delivered, or failed
- [ ] A Wedding Admin or Editor can resend a failed Notification
- [ ] Notification delivery status is visible per Guest in the Guest list
- [ ] The sender name displayed to the Guest is configurable per Wedding (couple names or planner agency name)
