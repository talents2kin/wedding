# 13 — Seating plan — visual drag-and-drop

**What to build:** Paid Wedding Admins and Editors get a visual floor plan view of the Seating Plan in addition to the list view. Tables appear as shapes on a canvas; Guests can be dragged from the unassigned pool onto a Table, and between Tables. This feature is locked for free-tier users — they see the list-based view only, with an upgrade prompt where the visual view would appear.

**Blocked by:** 12 — Seating plan — list-based + export.

**Status:** ready-for-agent

- [ ] Paid users see a visual floor plan showing Tables as shapes on a canvas
- [ ] Guests can be dragged from the unassigned pool onto a Table in the visual view
- [ ] Guests can be dragged from one Table to another in the visual view
- [ ] Changes made in the visual view are immediately reflected in the list view (same underlying data)
- [ ] Free-tier users see the list view only; the visual view shows an upgrade prompt in its place
- [ ] The visual floor plan is usable on a tablet-sized screen as well as desktop
