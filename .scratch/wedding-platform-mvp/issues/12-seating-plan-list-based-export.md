# 12 — Seating plan — list-based + export

**What to build:** A Wedding Admin or Editor can create a Seating Plan for a Ceremony by defining Tables (name and capacity) and assigning Guests to Tables. The plan shows which Guests are unassigned so the organiser knows when the plan is complete. The completed Seating Plan can be shared via a read-only link (no login required) and exported as a PDF for printing at the venue.

**Blocked by:** 05 — Guest list — manual entry + groups, 07 — RSVP tracking.

**Status:** ready-for-agent

- [ ] A Wedding Admin or Editor can create a Seating Plan for a specific Ceremony
- [ ] Tables can be added with a name and a capacity (number of seats)
- [ ] Guests confirmed for the Ceremony can be assigned to a Table
- [ ] The plan shows a count of assigned vs. total capacity per Table
- [ ] Unassigned Guests (confirmed but not yet seated) are listed separately and clearly visible
- [ ] A Wedding Admin or Editor can move a Guest from one Table to another
- [ ] A Wedding Admin or Editor can remove a Guest from a Table (returns them to the unassigned list)
- [ ] A read-only share link gives anyone with the link a view-only Seating Plan with no login required
- [ ] The Seating Plan can be exported as a PDF formatted for printing
- [ ] A Wedding Viewer can see the Seating Plan but cannot modify it
