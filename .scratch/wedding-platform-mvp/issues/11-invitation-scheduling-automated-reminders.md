# 11 — Invitation scheduling + automated reminders

**What to build:** A Wedding Admin or Editor can schedule a digital Invitation send for a future date and time, rather than sending immediately. They can also configure an automated RSVP reminder that sends to all Guests with a pending RSVP after a configurable number of days. Scheduled sends fire at the right time without manual action. The organiser can view, edit, and cancel scheduled sends and reminders before they fire.

**Blocked by:** 08 — Invitation template catalog + digital delivery.

**Status:** ready-for-agent

- [ ] A Wedding Admin or Editor can schedule a Notification for a future date and time
- [ ] Scheduled Notifications fire automatically at the configured time
- [ ] A Wedding Admin or Editor can view all pending scheduled Notifications
- [ ] A Wedding Admin or Editor can cancel a scheduled Notification before it fires
- [ ] A Wedding Admin or Editor can configure an automated RSVP reminder: choose the channel (email / SMS / WhatsApp) and the number of days after which it sends to Guests whose RSVP is still pending
- [ ] The automated reminder fires on schedule and only targets Guests still in pending status at fire time
- [ ] A Wedding Admin or Editor can disable an active automated reminder
