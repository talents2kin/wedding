# 09 — PDF invitation + QR code

**What to build:** A Wedding Admin or Editor can generate a downloadable PDF Invitation for any Guest for a specific Ceremony. The PDF is built from the selected Template and includes the Guest's name, Ceremony details, and a QR code that is unique to that Guest-Ceremony pair. The QR code can later be used for check-in (T14). The PDF can be downloaded individually or in bulk for all Guests in a Ceremony.

**Blocked by:** 05 — Guest list — manual entry + groups, 08 — Invitation template catalog + digital delivery.

**Status:** ready-for-agent

- [ ] A Wedding Admin or Editor can generate a PDF Invitation for a Guest for a specific Ceremony
- [ ] The PDF is rendered from the selected Template with the Guest's name and Ceremony details
- [ ] Each PDF contains a QR code uniquely identifying the Guest-Ceremony pair
- [ ] The QR code is scannable by a standard mobile camera
- [ ] A Wedding Admin or Editor can download a PDF for a single Guest
- [ ] A Wedding Admin or Editor can bulk-download PDFs for all Guests assigned to a Ceremony as a ZIP archive
