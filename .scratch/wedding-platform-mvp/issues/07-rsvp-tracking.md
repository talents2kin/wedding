# 07 — RSVP tracking

**What to build:** A Wedding Admin or Editor can manually update any Guest's RSVP status (confirmed / declined / pending) per Ceremony — covering responses received by phone or in person. The Wedding dashboard shows a live RSVP summary per Ceremony (confirmed count, declined count, pending count). RSVP status is tracked per Guest-Ceremony pair, so the same Guest can be confirmed for the civil ceremony and pending for the coutumier.

**Blocked by:** 05 — Guest list — manual entry + groups.

**Status:** ready-for-agent

- [ ] Each Guest has an RSVP status (confirmed / declined / pending) independently for each Ceremony they are assigned to
- [ ] A Wedding Admin or Editor can update a Guest's RSVP status for any Ceremony
- [ ] The Wedding dashboard shows confirmed, declined, and pending counts per Ceremony
- [ ] The Guest list reflects each Guest's RSVP status per Ceremony
- [ ] A Wedding Viewer can see RSVP statuses but cannot update them
