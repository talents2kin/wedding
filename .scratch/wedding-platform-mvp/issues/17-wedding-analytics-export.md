# 17 — Wedding analytics + export

**What to build:** A Wedding Admin or Viewer sees a dashboard summarising the full Wedding: RSVP breakdown per Ceremony (confirmed / declined / pending), table occupancy per Ceremony, Notification delivery stats (sent / delivered / failed), and meal preference totals per Ceremony. Planners see an aggregate dashboard across all their Weddings showing upcoming dates, total guest counts, and RSVP rates. Any report can be exported as PDF or Excel.
