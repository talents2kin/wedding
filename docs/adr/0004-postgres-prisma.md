# PostgreSQL + Prisma as the database and ORM

PostgreSQL is the write and read database. Prisma is the ORM and migration tool. The alternative considered was Drizzle (lighter, closer to raw SQL, faster at runtime) and Supabase (managed Postgres with built-in auth and storage). Prisma was chosen over Drizzle because its schema-first workflow and auto-generated types integrate cleanly with the Next.js App Router and reduce boilerplate for a data-heavy domain (Guests, Ceremonies, RSVP records, Notifications) where the schema will evolve frequently. Supabase was not chosen because it introduces a vendor dependency on auth and storage that would conflict with our white-label and GDPR requirements (EU data residency, self-controlled retention). Plain PostgreSQL gives us full control over data location and schema.
